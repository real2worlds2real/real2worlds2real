# Reconstruct an object

Identify the parts, material regimes, intended motion, supporting surfaces and hidden geometry from the current capture. Retrieve the mechanism's [experience module](../twin-model/references/experience/index.md). For a threaded cap, combine vessel and mating-thread methods. Separate evidence for both mating profiles, travel under rotation and retention on axial pull. Keep uncertain interiors explicit. Use fresh source evidence for each new capture. For a bonded leaf, petal or sheet, inspect [attachment and release](../twin-model/references/experience/flexible-bonded-surfaces.md). When its depth is ambiguous, inspect [thin-surface depth across views](../twin-model/references/experience/observed-surface-depth.md).

Use one target ID in the [model revision workflow](../../../end_to_end/docs/reconstruction.md). Start with agent-authored Blender. Include the editable source, dependent resources and semantic or physical declarations used in the build. Plan source fit and mechanism checks on this revision. A precise table is an object with its own support geometry and review; reference that same support in the assembled scene.

Choose metric fitting when calibrated masks, support and scale evidence exist. Choose the posed fitter for a selected set of registered observations. Inspect the fitted parameters and residuals before adopting any update. A better projection can still close the mouth of a vessel or erase a thread. Recheck geometry in neutral and held-out views. An explicit template fallback requires the same evidence.

Choose tests from actual parts and contacts. For a deformable, examine the rest shape, release, material motion, self-contact and the requested interaction on the target backend. For a rigid body, retain shape, inertia, stable support and functional clearance. A revision after a jam or incorrect deformation needs a fresh check. Select native execution details from [metric modeling](../twin-model/SKILL.md) and [workspace modeling](../generate-editable-object/SKILL.md).

When learning a procedure, record applicability, alternatives that failed, required operations and the outputs that were inspected. Distinguish source transfer, a tool actually exercised, and physical evidence in a particular simulator.
