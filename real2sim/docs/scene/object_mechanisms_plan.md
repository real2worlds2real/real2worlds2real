# Object mechanisms

Identify the parts visible in the capture, their materials, attachment and relative motion. Record each observation, uncertainty and task-relevant interaction in the object contract before choosing a representation. Distinguish an inferred mechanism from one observed in motion.

Build the visible geometry and physical contact surfaces together. A hinge needs an axis and limits, a threaded closure needs mating surfaces, and a flexible part needs material response and boundary conditions. Preserve the input rest state and record the units and coordinate frames used by the simulator.

Render the assembled object against the source views. Exercise the interaction on the native backend, inspect contact and motion, and use an independent physical check appropriate to the mechanism. Revisit the model when a geometry or material change invalidates that evidence. See the [representation-specific procedures](mechanism_reference.md).
